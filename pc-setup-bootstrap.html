New PC Setup

Open PowerShell (Win+X → Terminal) and run these steps in order.

1 Install Git and GitHub CLI
PS PowerShell 
winget install Microsoft.Git --accept-source-agreements --accept-package-agreements
winget install GitHub.cli --accept-source-agreements --accept-package-agreements
$env:Path = [System.Environment]::GetEnvironmentVariable("Path","Machine") + ";" + [System.Environment]::GetEnvironmentVariable("Path","User")
2 Authenticate to GitHub

Follow the browser prompts when they open.

PS PowerShell 
gh auth login
3 Clone and run installer

This pulls down pc-setup and runs the full installer. Takes ~10 minutes.

PS PowerShell 
gh repo clone marcusash_microsoft/pc-setup C:\GitHub\pc-setup
cd C:\GitHub\pc-setup
powershell -ExecutionPolicy Bypass -File .\install.ps1
What the installer does: Git, VS Code, PowerShell 7, Node.js, Oh My Posh, GitHub Copilot app, shell profiles, themes, repo cloning, Forge identity, Inkwell, MCP servers.
Re-run safe: If something fails, just run .\install.ps1 again. Already-installed items are detected and skipped. Use -SkipApps, -SkipGit, -SkipThemes, -SkipRepos to skip sections.
